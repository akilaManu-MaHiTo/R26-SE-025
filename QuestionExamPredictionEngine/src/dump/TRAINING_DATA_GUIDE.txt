==============================================================================
FIELD DESCRIPTIONS
==============================================================================

Required fields in student_report.json:

student_id (string)
  - Unique identifier for the student
  - Example: "s2024001", "it25100001"

exam (string)
  - Name of the exam/course
  - Example: "IT2040 – Database Management Systems"

year (integer)
  - Year the exam was taken
  - Example: 2024, 2025

question (string or integer)
  - Question number
  - Example: "1", "2", "3"

part (string)
  - Part of the question
  - Example: "a", "b", "c"

topic (string) ★ CRITICAL FOR WEAK TOPIC MODEL
  - Curriculum topic covered by this question
  - Example: "Entity-Relationship Modeling", "Normalization"
  - Should be SAME across multiple students if they answer same concept

learning_score (float, 0-1) ★ USED TO LABEL WEAK
  - Composite score of student performance
  - Formula: 0.6*performance + 0.25*concept + 0.15*cognitive
  - Students with score < 0.5 on a topic = "weak in that topic"

performance_score (float, 0-1)
  - Marks obtained / max marks
  - Based on grading rubric

concept_score (float, 0-1)
  - Keyword/concept extraction accuracy
  - Higher if student uses correct terminology

cognitive_score (float, 0-1)
  - Bloom's taxonomy level demonstrated
  - Based on question complexity vs student response

student_level (string)
  - Bloom's level student demonstrated
  - Values: "remember", "understand", "apply", "analyze", "evaluate", "create"

required_level (string)
  - Bloom's level required by the question
  - Values: same as above

average_level_gap (calculated during model training)
  - required_level - student_level
  - Positive = student below requirement
  - Negative = student above requirement

==============================================================================
KEY NUMBERS TO REMEMBER
==============================================================================

For a WEAK topic to be labeled "1" during training:
  ✓ students_attempted >= 2
  ✓ weak_student_share >= 0.4 (i.e., ≥ 40% of students score < 0.5)

For GOOD training data:
  ✓ Total records: 300+ (ideally 500+)
  ✓ Unique students: 30+ (ideally 50+)
  ✓ Unique topics: 10+ (ideally 20+)
  ✓ Exams/cohorts: 2+ (ideally 3-5)
  ✓ % weak topics: 30-50%
  ✓ % low-scoring records: 15-30%
