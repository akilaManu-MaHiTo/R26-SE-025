## Component Details

### Audio Extraction Component
```
INPUT: Video File (any format)
  │
  ├─ FFmpeg Command
  │  ├─ Input: Video stream
  │  ├─ Output: Audio only
  │  ├─ Format: WAV
  │  ├─ Sample rate: 16kHz
  │  ├─ Channels: 1 (Mono)
  │  └─ Codec: PCM 16-bit
  │
OUTPUT: audio_temp.wav (16kHz, Mono)
```

### Feature Extraction Components

#### Librosa Features (13+)
```
INPUT: 16kHz Mono WAV
  │
  ├─ Load audio
  ├─ Compute MFCC (13 coefficients)
  ├─ Spectral analysis
  │  ├─ Centroid
  │  ├─ Rolloff
  │  └─ Bandwidth
  ├─ Rhythmic analysis
  │  ├─ Zero crossing rate
  │  ├─ RMS energy
  │  └─ Tempo + beats
  ├─ Pitch analysis
  │  └─ Chroma features
  │
OUTPUT: Dict with 13+ features
```

#### Parselmouth Features (20+)
```
INPUT: 16kHz Mono WAV
  │
  ├─ Load Sound object
  ├─ Pitch analysis (F0)
  │  ├─ Mean, Std, Min, Max
  │  └─ Voicing analysis
  ├─ Formant analysis
  │  ├─ F1 (mean, std)
  │  ├─ F2 (mean, std)
  │  └─ F3 (mean, std)
  ├─ Voice quality analysis
  │  ├─ Jitter (4 types)
  │  ├─ Shimmer (5 types)
  │  └─ HNR (Harmonicity)
  │
OUTPUT: Dict with 20+ features
```

#### Emotion Detection
```
INPUT: 16kHz Mono WAV
  │
  ├─ Load Wav2Vec2 Model
  ├─ Resample audio if needed
  ├─ Process through model
  ├─ Get logits/probabilities
  ├─ Classify emotion (7 classes)
  │  ├─ Neutral
  │  ├─ Happy
  │  ├─ Sad
  │  ├─ Angry
  │  ├─ Fearful
  │  ├─ Disgusted
  │  └─ Surprised
  │
OUTPUT: Dict with emotion + confidence
```

#### Transcription
```
INPUT: 16kHz Mono WAV
  │
  ├─ Load Whisper Model
  ├─ Transcribe audio
  ├─ Get segments
  ├─ Extract word timings
  ├─ Detect language
  │
OUTPUT: Dict with transcript + segments
```

## Processing Workflow

```
Step 1: User Initiates
  python audio_analyzer.py videos/viva_01.mp4
                           │
Step 2: Audio Extraction   ├─→ extract_audio()
                           │   └─→ audio_temp.wav (16kHz)
                           │
Step 3: Parallel Processing │
  ┌─────────────────────────┤
  ├─→ Transcription         │
  │   transcribe_audio()    │→ transcript + segments
  │                         │
  ├─→ Emotion Detection     │
  │   extract_emotion()     │→ emotion + confidence
  │                         │
  ├─→ Feature Extraction    │
  │   extract_features()    │→ 40+ features
  │                         │
Step 4: Consolidation      └─→ Merge all results
                               │
Step 5: Output Generation     ├─→ audio_analysis_output.json
                              └─→ grading_summary.json
```

## Error Handling & Fallbacks

```
Pipeline Execution
│
├─ Audio Extraction
│  └─ Error? → Fail & Stop (critical)
│
├─ Transcription
│  └─ Error? → Mark as failed, continue with other features
│
├─ Feature Extraction
│  ├─ Librosa features
│  │  └─ Error? → Set defaults, continue
│  ├─ Parselmouth features
│  │  └─ Error? → Set defaults, continue with Librosa
│
├─ Emotion Detection
│  └─ Error? → Mark as failed, continue
│
├─ Consolidation
│  └─ Merge whatever succeeded
│
└─ Output
   └─ Save results with component status indicators
```
